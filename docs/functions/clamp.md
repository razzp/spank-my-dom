# Function: clamp()

> **clamp**(`value`, `min`, `max`): `number`

Clamp a value to a minimum and maximum boundary. If the value is within
both boundaries then it is returned unchanged.

## Parameters

### value

`number`

The value to clamp.

### min

`number`

The minimum value at which to clamp.

### max

`number`

The maximum value at which to clamp.

## Returns

`number`
