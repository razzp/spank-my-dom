# Function: randomInt()

> **randomInt**(`min`, `max`): `number`

Generate a random integer within a specified range.

## Parameters

### min

`number`

The minimum integer to generate.

### max

`number`

The maximum integer to generate.

## Returns

`number`

## Remarks

If you want to allow floating-point numbers,
consider using [randomNumber](randomNumber.md) instead.

## Example

Generate a random integer.
```ts
const result = randomInt(-10, 10);
```
